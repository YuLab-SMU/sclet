13 State Priority and Perturbation Sensitivity

After clustering, annotation, and trajectory analysis, one question still remains: which states actually respond to the perturbation? Not every cluster changes meaningfully between conditions, and some rare populations may drive the phenotype while being numerically small. This mainline is about ranking states by their responsiveness and detecting rare populations that deserve follow-up before everything else.

sclet now provides the three entry points that were promised in the mainline roadmap: RunPerturbationPriority(), RunRareCellDetection(), and RunStatePriorityWorkflow().

The core engine for perturbation priority is the Augur framework. Augur trains a machine-learning model for each cell type to predict experimental condition (e.g., treatment vs control) from molecular measurements. The cross-validated AUC of each cell-type-specific classifier becomes the priority score: a higher AUC means cells of that type are more distinguishable between conditions, and therefore more responsive.

13.1 Perturbation Priority Workflow

13.1.1 One-Step Dispatch

The simplest entry point is RunStatePriorityWorkflow(). It delegates to Augur behind the scenes and records the workflow as a structured analysis mainline record.

library(sclet)
sce <- pbmc

# The object must have condition labels and cluster labels in colData.
sce$condition <- ifelse(seq_len(ncol(sce)) %% 2 == 0, "treated", "control")

sce <- RunStatePriorityWorkflow(
    sce,
    condition_col = "condition",
    group_col = "colLabels",
    run_perturbation_priority = TRUE
)

13.1.2 Direct Augur Call

If you prefer to work directly with the Augur backend without the workflow shell, use RunPerturbationPriority().

The real Augur run is not executed during book rendering because it requires the Augur package and involves a non-trivial cross-validation loop. The code below shows the intended usage pattern.

library(sclet)
sce <- pbmc
sce$condition <- ifelse(seq_len(ncol(sce)) %% 2 == 0, "treated", "control")

sce <- RunPerturbationPriority(
    sce,
    condition_col = "condition",
    group_col = "colLabels",
    name = "my_augur_run"
)

# Inspect the AUC ranking
priority <- get_perturbation_priority(sce)
print(priority$AUC)

13.1.3 Inspecting Results

After the analysis, sclet stores the Augur output through two accessor layers. get_perturbation_priority() returns the complete priority record; has_perturbation_priority() checks whether the result is available.

# Check whether priority results exist
has_perturbation_priority(sce)
## [1] FALSE
# Retrieve the AUC table
auc_table <- get_perturbation_priority(sce, element = "AUC")
head(auc_table)

13.2 Rare Cell Detection

RunRareCellDetection(method = "density") identifies rare and major cell populations using a mutual-connectivity metric computed directly on the kNN graph. No external packages beyond BiocNeighbors (already a sclet dependency) are needed. The algorithm works in three steps on any reduction (typically PCA):

  1. Build kNN graph and compute each cell’s mutual connectivity (Q = fraction of neighbors that mutually connect back).
  2. Identify high-Q seeds — cells above q_threshold are local density maxima.
  3. Label propagation — unlabeled cells adopt the label of their most frequent labeled neighbor over 5 iterations. Clusters ≤ rare_threshold cells are flagged as rare.
library(sclet)
sce <- pbmc

# Ensure PCA is in the object (already there from core workflow)
sce <- RunRareCellDetection(
    sce,
    method = "density",
    reduction = "PCA",
    dims = 1:10,
    k = 20,
    q_threshold = 0.25,
    rare_threshold = 10,
    name = "density_demo"
)
